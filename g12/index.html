The Poverty Penalty

Pharmaceutical Dependency Across Socio-Economic Quintiles

This dumbbell plot visualizes the dispensing disparity between the poorest (First) and wealthiest (Fifth) quintiles. While baseline infections affect populations relatively equally, reliance on systemic medications (Metabolism, Nervous, Cardiovascular) spikes dramatically in lower-income communities, revealing deep healthcare inequality.

Note: Data represents the per-capita dispensing rate (Volume / Quintile Population). Red points indicate the poorest quintile, while blue points represent the wealthiest.
